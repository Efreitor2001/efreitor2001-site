# efreitor2001.ru

Одностраничный сайт-визитка Ефрейтор2001. Статический HTML/CSS, без сборки и серверных зависимостей. Подготовлен для GitHub Pages.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер из корня проекта.

## GitHub Pages и домен Timeweb

В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main`, папка `/ (root)`, и сохраните. Файл `CNAME` уже задаёт домен `efreitor2001.ru`. В поле **Custom domain** должно быть указано то же имя; после появления сертификата включите **Enforce HTTPS**.

В DNS-редакторе Timeweb замените существующие A-записи корневого домена на четыре адреса GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Для `www` удалите A-записи и добавьте CNAME `www` → `Efreitor2001.github.io`. Не меняйте NS/MX/TXT записи почты. Перед этим настройте домен в GitHub Pages, чтобы адрес был закреплён за аккаунтом.
